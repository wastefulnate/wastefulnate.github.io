# SiteControl SA

A real-time digital operations, Occurrence Book (OB), and automated overtime tracking platform designed for South African security firms.

🔗 **Public Case Study:** [https://wastefulnate.github.io](https://wastefulnate.github.io)  
🚀 **Live Prototype:** [https://sitecontrol-sa.onrender.co](https://sitecontrol-sa.onrender.com/)  
🔑 **Demo Credentials:** demo@sitecontrol.co.za / Security2026!


## Overview
Security companies traditionally rely on physical paper Occurrence Books (OBs) on-site and manual spreadsheet reconciliations at month-end. SiteControl SA replaces paper logs with a mobile-friendly web interface, real-time management dashboard, automated overtime calculation, and audit-ready PDF reporting.

## Key Features
* **Digital Occurrence Book (OB):** Mobile-first incident and shift logging for on-site guards and supervisors.
* **Attendance & Overtime Engine:** Automated tracking of shift hours and overtime flags to prevent payroll discrepancies.
* **Operations Dashboard:** Centralized view of active sites, shift statuses, and recent incidents.
* **PDF Reporting:** One-click generation of daily, weekly, and monthly incident and attendance summaries for clients and payroll.

## Tech Stack
* **Backend:** Python, Django
* **Database:** PostgreSQL
* **Deployment:** Render
